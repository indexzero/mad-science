# Primary specs

Copies of the primary spec documents that the research cites. Each file
is a snapshot. `MANIFEST.csv` gives the source URL, the retrieval time,
the HTTP status, and the SHA-256 of each file.

To add a spec, add an entry to `sources.json`. Then run `pnpm specs`.
To download every file again, run `pnpm specs -- --refresh`.

The copyright of each document stays with its authors. The copies keep
the original text and its license notice. They exist so that the
research can be checked against the exact text that it cites.
